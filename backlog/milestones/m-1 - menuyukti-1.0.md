## Description

Define and ship Menuyukti 1.0 as a stable local MCP product for restaurant owners.

**In scope (product contract):** tools + visualisations for venue slot strength, menu heatmaps, pair lift index, and weak items analysis — so owners can plan promotions and trim/compact the menu.

**Out of scope for 1.0:** features not required for those two owner outcomes (to be listed in the scope decision).

First work is documenting and freezing that definition; then gap-audit; then cut the release.
